상품·이용 안내

상세 풀이 상품의 최종 결제 금액은 19,000원이며, 개인 입력 정보로 제작한 15쪽 PDF 1부와 구매 브라우저에서의 같은 내용 열람을 제공합니다. 무료 풀이와 샘플 PDF는 결제 없이 이용할 수 있습니다.

사주는 한국 음력과 절입을 기준으로 계산하며 한국 표준시 UTC+9를 고정 적용합니다. 과거 표준시·서머타임·진태양시를 보정하지 않습니다. 시간 미상과 절입 경계는 불확정으로 표시합니다. 대운·용신·합충의 전문가 감정이나 의료·법률·투자 판단, 미래 사건 예측을 제공하지 않습니다.

현재 보고서 작성 방식: 기본 정형 해설. AI 해설을 사용하는 경우 구매 화면에서 그 사실과 계산 정보 전송 대상을 표시하고 별도 동의를 받습니다. 계산 결과는 AI가 임의로 다시 산출하지 않습니다.

결제 승인 후 자동 제작·발송을 시작합니다. 메일 업체 접수와 실제 수신은 다를 수 있습니다. 스팸함도 확인해 주세요. PDF와 웹 보고서는 주문 생성 후 30일 동안, 주문을 만든 브라우저의 임시 인증정보로 열람할 수 있습니다. 브라우저 정보 삭제·기기 변경 시 판매자 문의가 필요합니다.

취소·환불 안내

구매 브라우저의 주문 화면에서 문의 또는 환불 검토를 요청할 수 있습니다. 입력 정보를 잘못 적었거나 제작이 진행되지 않은 주문, 미제공·하자·오발송 등은 주문번호와 사유를 알려주세요. 운영자는 실제 제작·전달 상태와 관계 법령에 따라 검토하고 답변합니다.

환불 요청 접수만으로 카드 취소가 완료되지는 않습니다. 전액 환불이 승인되면 결제사의 취소 완료를 확인한 뒤 주문을 환불 완료로 표시합니다. 카드사 반영에는 추가 시간이 걸릴 수 있습니다. 제작 시작 동의만으로 법정 청약철회·소비자 권리가 일괄 배제되지는 않습니다.

전액 환불 후에는 보고서의 서버 열람과 재다운로드가 종료됩니다. 운영자가 처리 중인 결제를 다시 결제하지 말고, 같은 주문의 상태를 확인해 주세요. 고객센터 연락처는 페이지 상단의 판매자 정보를 확인하세요.

개인정보 수집·이용 및 보관

무료 계산의 이름·생년월일은 브라우저에서 계산하며 서버로 전송하지 않습니다. 유료 구매에서는 이름(선택), 출생 날짜·시각·달력 구분, 수신 이메일, 동의 이력과 주문·문의 정보를 보고서 제작·발송·고객 응대에 사용합니다. 필수 정보 이용에 동의하지 않으면 유료 주문을 진행할 수 없으며 무료 풀이는 이용할 수 있습니다.

출생 정보·이메일·PDF·웹 해설·문의 내용은 주문 생성 후 30일에 정리합니다. 결제·취소 금액, 주문번호 등 거래 장부는 별도로 보관합니다. 법정 보존 대상·기간과 백업 삭제 절차는 실제 판매자의 적용 법령 및 운영 정책에 맞게 확정합니다.

결제는 토스페이먼츠가 처리하며 카드번호를 사주문 서버에 저장하지 않습니다. 메일 발송을 위해 이메일 주소와 PDF가 Resend로 전달됩니다. AI 해설을 사용하는 경우 이름·이메일을 제외한 계산 명식·오행 정보가 OpenAI에 전송되며, API 요청에는 저장 비활성화를 지정합니다. 제공자 측 처리·보관 조건은 각 계약과 정책을 따릅니다. 판매자는 수탁·국외 이전의 대상·국가·방법·항목·시점·거부 방법 등 필요한 내용을 실제 계약에 맞게 확정하고 고지해야 합니다.

홍보 효과는 페이지 종류, 날짜, 캠페인 출처별 조회수를 합산합니다. 이름·생일·이메일·IP·고유 방문자 식별자를 통계에 저장하지 않으며, 동일인의 재방문을 포함한 조회수입니다. 출처를 구매에 연결하기 위해 브라우저의 해당 탭 임시 저장소를 사용하며 브라우저 세션 종료 시 사라집니다.

운영 서버는 개인 주문 데이터의 암호화 키와 관리자 접근 키를 필요로 합니다. 접근·정정·삭제·처리정지 요청은 판매자 연락처로 문의할 수 있습니다. 실제 판매 전 판매자 정보와 해당 개인정보 처리방침을 확정해야 하며, 이 초안만으로 운영에 필요한 모든 고지가 완료되었다고 보지 않습니다.
