무료로 로그인·주문·PDF 확인하기

무료 구성으로 변경했습니다

Render Free 웹 서버 + Neon Free PostgreSQL을 사용합니다. 유료 영구 디스크는 신청하지 않습니다. 서버가 재시작되어도 관리자 계정·로그인·주문·PDF는 Neon DB에 남습니다.

현재 설정은 청구 금액 0원의 무료 테스트입니다. 실제 카드 결제, 이메일 발송과 유료 AI 호출은 하지 않으며, 기본 해설로 만든 15쪽 PDF를 웹에서 읽거나 내려받습니다. 실제 계정 생성과 서비스 연결은 아래 순서로 직접 진행해야 합니다.

1. Neon에서 무료 DB 만들기

  1. Neon에 가입·로그인합니다.
  2. Free 요금제로 새 프로젝트를 만듭니다. 가능하면 Render에서 선택할 지역과 가까운 DB 지역을 고릅니다.
  3. Connect에서 PostgreSQL 연결 문자열(Connection string)을 복사합니다. 비밀번호가 포함되어 있으므로 채팅이나 GitHub에 붙여 넣지 않습니다.

이 연결 문자열은 다음 단계의 Render 보안 환경변수 DATABASE_URL에만 넣습니다. DB 이름이나 비밀번호를 임의로 바꾸지 말고 제공된 전체 문자열을 사용하세요.

2. Render에서 무료 서버 만들기

  1. Render에서 New + → Blueprint를 선택합니다.
  2. GitHub 저장소 moonhong1164/Saju_moon, 브랜치 gh-pages를 선택합니다.
  3. 저장소의 render.yaml을 읽었을 때 웹 서비스 요금제가 Free이고 유료 디스크가 없는지 확인합니다. Starter나 Disk 요금이 표시되면 생성하지 말고 최신 gh-pages 브랜치인지 확인하세요.
  4. DATABASE_URL 입력란에 Neon 연결 문자열을 넣습니다. 나머지 첫 계정 설정 키와 데이터 암호화 비밀값은 Render가 자동 생성하도록 구성되어 있습니다.
  5. 설정을 확인하고 생성합니다. 배포 상태가 Live가 될 때까지 기다립니다.

기존에 유료 서비스를 만들었다면 이 파일 변경만으로 그 서비스의 요금이나 디스크가 자동 취소되는 것은 아닙니다. 저장된 데이터가 있는 서비스를 임의로 삭제하지 마세요.

3. 관리자 계정 만들기

  1. Render가 만든 공개 서비스 주소 끝에 /admin.html을 붙입니다.
  2. Render 서비스의 환경변수 화면에서 ADMIN_SETUP_TOKEN 값을 본인만 확인합니다.
  3. 첫 설정 화면에 그 키와 원하는 아이디·비밀번호를 입력합니다. 비밀번호는 12자 이상입니다.
  4. 다음부터는 아이디·비밀번호로 로그인합니다. 로그인은 최대 8시간 유지됩니다.

ORDER_DATA_SECRET은 주문 암호화에 사용하는 비밀값입니다. 그대로 유지하고 별도로 안전하게 백업하세요. 계정 비밀번호와 다르며, 임의로 재생성하면 기존 주문을 읽을 수 없습니다. 키와 비밀번호는 채팅에 보내지 마세요.

4. 무료 테스트 주문 확인하기

같은 Render 서비스 주소의 /checkout.html을 엽니다. ‘0원 · 무료 테스트’와 ‘무료 테스트 PDF 만들기’가 표시됩니다. 첫 관리자 계정을 만든 뒤 입력 정보를 넣고 PDF를 제작할 수 있습니다.

PDF를 내려받고, 관리자에서 테스트 주문과 문의를 확인하세요. 테스트 주문 취소는 실제 환불이나 금액 이동이 아닙니다. 이메일은 발송하지 않습니다. 실제 무료 운영 주소는 배포가 완료된 Render 주소이며, 기존 GitHub Pages에는 서버 API가 없습니다.

무료 범위와 제한

  • Render·Neon의 Free 플랜 할당량 안에서 이용하는 구성입니다. 가입 화면의 최신 요금제와 제한을 확인하고 유료 업그레이드를 선택하지 마세요.
  • 테스트 주문은 비용·저장 용량 보호를 위해 하루 10건, 보관 100건으로 제한합니다. 이는 앱 자체 보호 한도이며 제공자의 무료 할당량과는 별도입니다.
  • 무료 서버와 DB는 대기 상태가 될 수 있어 처음 접속하거나 주문을 만들 때 시간이 걸릴 수 있습니다. 항상 실행되는 유료 서버와 같은 처리 시간을 보장하지 않습니다.
  • 서버가 쉬는 동안 작업은 DB에 남고 다음 실행 시 이어서 처리합니다. 메일 배달 시간이나 상시 작업 실행을 보장하지 않습니다.
  • 실제 카드 결제에는 결제사 수수료가 따르고 유료 AI API는 별도 비용이 있습니다. 현재 무료 테스트에서는 둘 다 호출하지 않습니다.
  • 자동 이메일은 현재 꺼져 있습니다. 나중에 메일 제공자 계정·발신 설정과 무료 발송 한도를 확인한 뒤 별도로 연결할 수 있습니다.
