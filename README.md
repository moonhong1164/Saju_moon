# 사주문 · Saju Moon

한국적 색감의 반응형 사주 랜딩 페이지와 브라우저 안에서 동작하는 사주 계산기입니다.

## 구현된 기능

- 양력 / 한국 음력 평달·윤달 입력, 음양력 변환
- 입춘 기준 년주, 12절 절입 기준 월주, 일주, 시주 계산
- 한국 표준시 UTC+9 고정, 일주 변경은 자정 기준
- 시간 미상 시 시주 제외, 절입 경계일·분의 불확정 기둥 표시
- 오행 개수, 일간별 종합·관계·일과 재물 참고 풀이
- 결과 복사, 모바일 레이아웃, 입력 오류 안내

이름·생일은 외부에 전송하거나 저장하지 않습니다. 계산 라이브러리를 `app.js`에 번들하여 외부 CDN/API 없이 동작합니다. 오픈소스 라이선스는 `THIRD_PARTY_NOTICES.txt`에 포함되어 있습니다.

## 실행

배포된 번들로 실행만 할 때는 Node 패키지 설치가 필요 없습니다.

```sh
cd /workspace/Saju_moon
python3 -m http.server 3000 --bind 0.0.0.0
```

## 수정·검증

Node.js 20 이상과 npm을 사용합니다. 원본은 `src/`에 있으며 `app.js`를 직접 수정하지 마세요.

```sh
cd /workspace/Saju_moon
npm ci --cache /tmp/sajumoon-npm-cache --no-audit --no-fund
npm test
npm run build
```

`npm test`는 알려진 간지와 음력 변환 예제, 입춘·경칩 경계, 자정·시각 경계, 시간 미상, 잘못된 날짜와 미래 생일을 검증합니다.

로컬 서버가 실행 중이고 Python Playwright 및 Chromium이 설치되어 있으면 다음 브라우저 검증도 가능합니다.

```sh
python3 tests/browser.py
```

브라우저 경로는 `CHROMIUM_PATH`, 테스트 주소는 `SAJU_TEST_URL`로 지정할 수 있습니다. 브라우저 검증에서는 서울·로스앤젤레스 시간대, 입력·결과·복사·모바일·개인정보 비전송을 확인합니다. 별도 Python 패키지나 브라우저 설치는 정적 사이트 실행에 필요하지 않습니다.

## 계산과 풀이 범위

- 1900년부터 오늘까지의 생일을 지원합니다. 음력은 한국 달력 데이터를 사용합니다.
- 절기 계산 라이브러리의 UTC+8 시각을 UTC+9로 환산해 년·월주를 구합니다. 일·시주는 입력한 한국 날짜·시각을 사용합니다.
- 시각을 분 단위로 입력하므로 해당 분 안에 절입이 발생하면 가능한 후보를 표시합니다. 시간 미상인 경계일도 후보를 표시합니다.
- 23시에도 날짜는 바뀌지 않으며, 시주 천간도 해당 날짜의 일간을 기준으로 합니다.
- 과거 한국 표준시 변경, 서머타임, 해외 출생지, 경도·진태양시 보정은 지원하지 않습니다.
- 오행은 확정된 표면 글자의 개수입니다. 지장간·계절 강약·신강신약·용신·대운 분석은 포함하지 않습니다.
- 풀이는 일간과 오행에 연결한 전통 상징 설명입니다. AI 개인 상담이나 미래 예측, 전문가 감정을 제공하는 서비스가 아닙니다.
