로그인 서버 연결이 필요합니다

GitHub Pages는 화면만 제공해 아이디·비밀번호를 확인하거나 주문을 저장할 수 없습니다. 현재 로그인 정보가 틀린 상태가 아니라, 관리자 서버가 연결되지 않은 상태입니다.

  1. Node 서버를 영구 저장소와 함께 배포합니다.
  2. 서버의 보안 설정에서 초기 설정 키를 등록합니다.
  3. 배포된 서버 주소의 관리자 페이지에서 첫 계정을 만듭니다.

게시 후 확인할 것

채널마다 다른 캠페인 링크를 사용하세요. 조회수만 보지 말고 구매 화면 진입, 생성 주문과 결제, 환불 및 문의를 함께 확인하세요. 실제 고객의 동의 없이 후기나 출생 정보를 홍보에 사용하지 마세요.

출시·운영 안내는 저장소의 OPERATIONS_GUIDE.md에서 확인할 수 있습니다.
